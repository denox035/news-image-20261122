# news-image-20261122

One image summing up the world's news of **Sunday 22 November 2026**:
the COP31 climate talks collapsing in Antalya with no deal, Iranian
strikes on US bases in Bahrain and tankers hit in the Strait of
Hormuz, a Russian drone flattening a block near Kyiv, a factory fire
in Cikande, Indonesia with dozens missing, BepiColombo reaching
Mercury orbit, and Friday's market sell-off.

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. The poster itself was
drawn programmatically with PIL — every letter is rendered, nothing
is AI-generated text.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
